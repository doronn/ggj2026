# Server Foundation

This folder is reserved for the dedicated-server and backend side of the persistent-world pivot.

## Intended responsibilities
- Player profile and world descriptors.
- Matchmaking for collision instances.
- Persistent world snapshot and delta storage.
- Background simulation workers.
- Collision resolution orchestration.

## Current status
- Unity-side contracts and DTOs exist under `Assets/_Game/Shared`.
- Server implementation is not wired yet.
- Use this folder for server projects and deployment assets in later milestones.
